An appearance and navigation update for Folio, the local Markdown editor.

## New in 0.1.1

- Independent light/dark and color scheme buttons. Paper, Sepia, Ocean, Forest, Nord and Graphite each support both modes.
- Resizable sidebar with remembered width, keyboard controls and double-click reset.
- Follow relative Markdown file links in tabs and jump to heading anchors.
- Zoom with Cmd on macOS or Ctrl on Windows/Linux: plus, minus and zero. Your zoom level is remembered.
- Open files and directories from the terminal. On macOS, run `npm run install:cli` from the source checkout to install the `folio` launcher, then use `folio ~/notes/`.
- Updated macOS installation instructions and optional signing support for future builds.

## Downloads

| Platform | Download | Install |
| --- | --- | --- |
| macOS Apple Silicon only | `Folio_0.1.1_macos-arm64.zip` | Extract and drag Folio.app to Applications. |
| Windows Intel/AMD 64-bit only | `Folio_0.1.1_windows-x64-setup.exe` | Run the setup installer. It installs WebView2 if needed, which requires internet access. |
| Linux Intel/AMD 64-bit only | `Folio_0.1.1_linux-x64.AppImage` | Make executable, then run. FUSE may be required; alternatively run with `--appimage-extract-and-run`. |
| Debian/Ubuntu Intel/AMD 64-bit only | `Folio_0.1.1_linux-x64.deb` | Install with `sudo apt install ./Folio_0.1.1_linux-x64.deb`. |

`SHA256SUMS.txt` contains checksums for the four downloads. No Intel Mac, Windows ARM, Linux ARM or 32-bit builds are included.

## macOS first launch

If macOS shows **Apple could not verify Folio is free of malware**, click **Done**. Open **System Settings > Privacy & Security**, scroll down to Security, click **Open Anyway** for Folio, then confirm **Open**. Only continue with a copy downloaded from this repository.

The 0.1.1 beta is ad-hoc signed and not notarized. [Full installation instructions and future signing setup](https://github.com/mozanunal/folio/blob/main/docs/macos-installation.md).

## Features

- Visual Markdown editing, GFM tables and task lists, and highlighted source mode.
- Inline and display LaTeX formulas, SVG and raster images, and Mermaid diagrams that follow the theme.
- Open individual files or directories, edit multiple tabs, and switch to a read-only view.
- Add and remove table rows and columns, copy code blocks, and switch between centered and full width layouts.
- Unsaved-change prompts and checks for external changes before overwriting files.

## Beta notes

These builds are unsigned by a trusted publisher. The macOS app is ad-hoc signed and is not notarized. macOS Gatekeeper or Windows SmartScreen may require an explicit allowance. On macOS, after trying to launch the app, use System Settings > Privacy & Security > Open Anyway if available. Only allow the app downloaded from this repository. Windows may show More info > Run anyway.

Markdown formatting can be normalized after visual edits, and unsupported syntax may not round-trip exactly. Keep backups of important documents. Exact source preservation, file watching, clipboard image import and tab restoration are still planned.

macOS file opening at launch and while running, and native window closing, have been manually checked. Windows and Linux packages are built and tested in CI; their desktop behavior and startup speed still need testing on real machines.

For the Windows test, open a file from Explorer, open a folder, edit a table and an equation, save and reopen, then close a window with unsaved changes. Please report issues with the operating system version and a small example document.
