A smaller diagram renderer with colors that follow your workspace.

## New in 0.1.2

- Pele 1.7.0 replaces Mermaid.js. Keep using the same fenced `mermaid` blocks.
- Diagram colors follow all six Folio color schemes and light/dark mode without re-rendering.
- Diagram types load on demand. Total emitted JavaScript in the local production build is approximately 61% smaller than 0.1.1, including lazy chunks. This is a bundle-size measurement, not a startup, RAM or rendering-speed benchmark.
- Expanded regression coverage for ten diagram types, error recovery and unchanged Markdown source.

## Compatibility

Pele uses its own layouts and visual style. Mermaid `theme` and `themeVariables` colors do not apply, arbitrary HTML labels are not supported, and external Mermaid plugins are not included. Folio disables links and embedded images inside diagrams; ordinary Markdown links and images continue to work separately. Source remains editable if a diagram cannot render. See [Pele compatibility](https://pele.run/compatibility).

## Updating an existing install

There is no automatic updater. Save your documents and quit Folio, then replace the application using the new download:

- macOS: extract the ZIP and replace Folio.app in Applications.
- Windows: run the new setup installer using the same installation location.
- Linux AppImage: replace the old AppImage and make the new one executable.
- Debian/Ubuntu: install the new `.deb` with apt.

Your Markdown files stay in their existing locations. Open tabs are not restored after quitting.

`SHA256SUMS.txt` contains checksums for the four downloads. No Intel Mac, Windows ARM, Linux ARM or 32-bit builds are included.

## macOS first launch

If macOS shows **Apple could not verify Folio is free of malware**, click **Done**. Open **System Settings > Privacy & Security**, scroll down to Security, click **Open Anyway** for Folio, then confirm **Open**. Only continue with a copy downloaded from this repository.

The 0.1.2 beta is ad-hoc signed and not notarized. [Full installation instructions and future signing setup](https://github.com/mozanunal/folio/blob/main/docs/macos-installation.md).

## Beta notes

Visual edits can normalize Markdown formatting. Unsupported syntax may not round-trip exactly, so keep backups of important documents. Clipboard image import, file watching, directory search and restoring tabs after quitting remain planned.

Windows and Linux packages run automated frontend and Rust checks in CI. Their interactive desktop behavior still needs testing on real machines. The Pele integration has automated renderer and editor coverage; manual cross-platform rendering checks and performance benchmarks remain outstanding.
