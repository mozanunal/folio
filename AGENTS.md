# Project instructions

Write self-documenting code. Add comments only for genuinely non-obvious logic.

Do not use em dashes or en dashes in documents.

Do not use Git worktrees unless explicitly requested.

Keep typing responsive. Avoid full-document parsing, serialization, filesystem access, or diagram rendering on every keystroke. Test preservation of document content before expanding supported syntax.

Do not claim performance or platform compatibility from architecture alone. Measure release builds, and distinguish verified behavior from prototype implementation.
